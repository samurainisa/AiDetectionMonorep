# Диаграммы для магистерской защиты

## Что добавить в презентацию

Оптимальный набор - две дополнительные схемы:

1. **Пайплайн обучения и применения модели** - показывает исследовательскую часть: датасет, подготовку, обучение RuBERT/BERT, метрики и использование модели в системе.
2. **Пайплайн обработки документа** - показывает внутреннюю логику продукта: загрузка, извлечение текста, анализ, антиплагиат, отчет и история.

Этого достаточно. Диаграмма классов или строгая DFD-схема для основной презентации будут перегружать слайды.

## Куда вставить

После слайда с предлагаемым решением:

1. Архитектура системы.
2. Пайплайн обработки документа.
3. Обучение и применение модели.
4. Интерфейсы системы.

Так получается логичная последовательность: технологии -> архитектура -> алгоритм работы -> ML-методика -> интерфейс.

## На чем основаны схемы

- ML-пайплайн основан на `AiDetectionML/scripts/01_inspect_dataset.py`, `02_prepare_dataset.py`, `03_train_model.py`, `04_evaluate_model.py`, `configs/train_config.yaml` и сохраненной модели `models/rubert_tiny2_ai_detector`.
- Пайплайн обработки документа основан на `AiDetectionBackend/app.py`, `utils/file_processing.py`, `services/detection_service.py`, `core/local_ml_client.py`, `core/pangram_client.py`, `plagiarism_engine.py` и frontend-вызовах из `AiDetectionFrontend/src/services/api.ts`.
